# KWide - Website Institucional

Website institucional, comercial e de marketing de alta conversão para a plataforma KWide.

**Transformando qualquer mesa em um canal inteligente de vendas.**

## 🚀 Tecnologias

- **Next.js 14** - Framework React
- **TailwindCSS** - Estilização
- **Framer Motion** - Animações
- **React i18next** - Internacionalização (PT-BR, EN, ES)

## 📋 Requisitos

- Node.js 18+
- npm ou yarn

## 🔧 Instalação

```bash
# Clone o repositório
git clone https://github.com/andre-gusmao/kwide-site.git
cd kwide-site

# Instale as dependências
npm install

# Configure as variáveis de ambiente
cp .env.local.example .env.local

# Rode o servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000)

## 📁 Estrutura do Projeto

```
kwide-site/
├── components/          # Componentes reutilizáveis
├── pages/              # Páginas da aplicação
├── public/             # Arquivos estáticos
├── styles/             # Estilos globais
├── locales/            # Arquivos de tradução
└── lib/                # Funções utilitárias
```
